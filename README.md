
# ML Rock Paper Scissors

An interactive Rock Paper Scissors game using a custom-trained image classification model and Scratch.

## About the Project

This project combines machine learning with an interactive Scratch game.

I used Machine Learning for Kids (ML4K) to collect image examples of three hand gestures:

- Rock
- Paper
- Scissors

I trained the model to recognize these gestures through a camera and connected it to Scratch to use the detected gestures in an interactive Rock Paper Scissors game.

## Tools Used

- Machine Learning for Kids (ML4K)
- Scratch
- Camera-based image classification

## Project Workflow

1. Collected image examples for rock, paper, and scissors.
2. Trained a machine learning model using ML4K.
3. Tested the model's gesture predictions.
4. Connected the trained model to Scratch.
5. Built an interactive Rock Paper Scissors game.

## Repository Contents

- `scratch-game/` — Scratch game project file.
- `screenshots/` — Evidence of data collection, model training, testing, and gameplay.
